Storm Chart Android source. See README-AR.md for Arabic build instructions.

Build requirements: Android SDK 35, JDK 17, Gradle 8.9.
Application id: com.stormchart.app
Version: 1.0.0
Min SDK: 24

The project uses XAUS public gold spot API (no key, 60-second cache) and Frankfurter daily FX reference rates. It does not provide second-by-second gold quotes, broker execution prices, or full Pine Script compatibility.
