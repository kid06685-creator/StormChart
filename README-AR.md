# Storm Chart — مشروع Android

## تحويل المشروع إلى APK مجاناً عبر GitHub Actions

1. نزّل ملف ZIP وفك الضغط عنه.
2. افتح https://github.com وسجّل الدخول أو أنشئ حساباً مجانياً.
3. اضغط علامة `+` ثم `New repository`.
4. اكتب اسماً مثل `storm-chart` واختر `Public` أو `Private` ثم `Create repository`.
5. من صفحة المستودع اضغط `Add file` ثم `Upload files`.
6. افتح المجلد الذي فككت ضغطه، وارفع **كل محتوياته** إلى المستودع. يجب أن يظهر `app` و`build.gradle` و`settings.gradle` ومجلد `.github` في الجذر.
   - إذا لم يظهر `.github` في مدير الملفات، فعّل إظهار الملفات المخفية، أو ارفع مجلد `.github/workflows/android-apk.yml` يدوياً.
7. اضغط `Commit changes`.
8. افتح تبويب `Actions`.
9. اختر `Build Storm Chart APK` ثم `Run workflow` ثم زر `Run workflow` الأخضر.
10. انتظر حتى تصبح علامة التشغيل خضراء. افتح نتيجة التشغيل، وانزل إلى `Artifacts`، ثم نزّل `Storm-Chart-APK`.
11. فك ضغط ملف Artifact؛ بداخله `app-debug.apk`. افتحه على هاتف Android واسمح بالتثبيت من هذا المصدر إذا طلب الهاتف ذلك.

## المتطلبات
- Android 7.0 أو أحدث.
- اتصال إنترنت لبيانات الأسعار.
- لا يلزم API key أو اشتراك مدفوع لمصدر الذهب المدمج.

## مصادر البيانات وحدودها
- الذهب XAU/USD: `https://xaus.com/api/v1/spot?compact=1` دون مفتاح. السعر المرجعي مخزّن مؤقتاً 60 ثانية، لذا لا يمكن ضمان تغيره كل ثانية. يلتزم التطبيق بطلب تحديث كل 60 ثانية لتجنب تكرار طلبات لا تعطي بيانات أحدث.
- تاريخ الذهب اليومي: XAUS history.
- سجل الذهب داخل اليوم: XAUS intraday بعينات مسجلة كل 5 دقائق. القيم المتاحة هي نقاط سعرية وليست شموع OHLC أصلية؛ يعرضها التطبيق كشموع مشتقة بوضوح.
- الفوركس: Frankfurter مرجع يومي فقط؛ ليس بث فوركس لحظياً ولا بيانات وسيط.
- الأسعار مرجعية إرشادية وليست أسعار تنفيذ أو تداول لدى وسيط.

## حدود النسخة
هذه نسخة أولية قابلة للبناء، وليست بديلاً مكتملاً عن TradingView. محرر Storm Pine يحفظ النص فقط ولا ينفذ Pine Script. أدوات الرسم في هذه النسخة واجهة تفاعلية أولية، وبعض الأنواع والمؤشرات تحتاج استكمالاً. APK الناتج من workflow هو Debug APK موقّع بمفتاح debug، مناسب للاختبار والتثبيت اليدوي، وليس إصدار متجر Google Play.
